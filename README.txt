МОЯ КОРЗИНА — установка на iPhone

В приложении можно:
- добавлять товары и количество;
- отмечать купленное;
- менять порядок перетаскиванием за значок ⋮⋮ или стрелками вверх/вниз;
- удалять отдельные товары и очищать купленное;
- сохранять список на устройстве.

ВАЖНО: чтобы установить приложение как значок на главный экран iPhone,
эти файлы нужно сначала разместить на HTTPS-сайте (например, GitHub Pages).
Затем откройте адрес сайта в Safari → Поделиться → На экран Домой → Добавить.

Данные списка хранятся локально в браузере на этом iPhone.
